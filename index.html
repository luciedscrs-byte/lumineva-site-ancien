Comment lire ce site

Trois mots reviennent : fait (un chiffre calculé dans les fichiers, qu’on peut vérifier), interprétation (une explication possible, non démontrée) et limite (ce qui peut fausser la lecture). Une décision chiffrée suit sept étapes : question, hypothèse, périmètre, test, effet, chiffre, décision. Une recommandation donne un conseil et un plafond de dépense quand les données ne permettent pas de prouver. Tout le code qui produit les chiffres est affiché dans les pages et listé dans « Méthode et code ».
