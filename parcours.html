Parcours clients

Comment un client évolue entre sa première commande et les suivantes, quels profils se dégagent, et ce que contient une première commande.

Ce que ça mesure
Ce qui change et ne change pas entre la 1re commande et les suivantes (montant, prix, produits), des profils de clients construits automatiquement, et la composition d’une 1re commande.
Sur quel périmètre
829 clients identifiés dont 248 ont commandé au moins 2 fois. Commandes annulées et ligne « pourboire » exclues. Le niveau de vie est la médiane de la commune de livraison (Insee 2020), à défaut du département.
Ce que ça permet de conclure
Voir que le panier monte de 4,38 € entre la 1re et la 2e commande par le prix des articles et non par leur nombre, que les clients restent sur une famille de produits mais changent de produit, et que cinq profils de comportement se distinguent.
Ce que ça ne permet pas de conclure
Prédire qui reviendra : l’arbre de décision ne fait guère mieux que le hasard (AUC 0,55). Le lieu et le niveau de vie ne distinguent presque pas les profils ; ce sont les comportements qui les séparent.
Comment lire cette page. Trois questions sur le parcours des clients : (1) qu'est-ce qui change entre la 1re commande et les suivantes ? (2) quels profils de clients trouve-t-on ? (3) que contient une 1re commande, et le retrouve-t-on ensuite ? Base : clients identifiés, commandes annulées exclues, ligne « pourboire » exclue. Les 25 commandes sans identifiant client ne peuvent pas être suivies. Chaque bloc distingue le fait, l'interprétation possible et la limite. Aucun nom, e-mail ou adresse n'est utilisé : uniquement des agrégats.

Ce qui change et ce qui ne change pas d'une commande à l'autre

Ce qui ne change pas
  • Le nombre d'articles (≈ 3,5 par commande).
  • La famille de produits : 226 clients sur 280 (81 %) rachètent au moins une famille déjà achetée à la 1re commande.
  • Le poids des bougies gourmandes (71 % des 1res commandes, 65 % des 2es).
  • Le retrait local (≈ 18 à 19 % des commandes).
Ce qui change
  • Le produit exact : seulement 69 clients sur 280 (25 %) rachètent le même produit ; 10 % des produits de la 2e commande ont déjà été achetés.
  • La famille dominante : identique pour 130 clients sur 280 (46 %).
  • 172 clients sur 280 (61 %) découvrent une nouvelle famille à la 2e commande.
  • Le code promo : 53,6 % → 13,3 %.
  • Le montant de la 2e commande : plus élevé pour 133 clients, moins pour 101, à ±5 € pour 46.

Interprétation possible : le client fidèle reste sur l'univers « bougie » mais change de parfum, ce qui est cohérent avec un catalogue de parfums de saison. Limite : le catalogue change avec les lancements, donc « ne rachète pas le même produit » peut simplement vouloir dire que le produit n'existe plus.

Ville et niveau de vie : ne distinguent presque pas les profils

Fait : le niveau de vie médian de la commune est quasi identique d'un profil à l'autre (de 21 800 € à 23 660 € par an et par unité de consommation, Insee 2020), et la taille de la commune aussi. Ce sont les comportements (fidélité, code promo, retrait local) qui séparent les profils. Source du niveau de vie : médiane de la commune de livraison (798 clients), à défaut celle du département ; 115 clients hors France reçoivent la valeur médiane.

Interprétation possible : la clientèle est géographiquement et socialement homogène (petites villes) ; la segmentation utile est comportementale. Limite importante : la séparation entre groupes est faible (indice de silhouette 0,17 pour 5 groupes, 0,24 pour 3 ; en dessous de 0,25 les groupes se chevauchent). Le choix de 5 profils est un choix de lecture, pas une frontière naturelle. Le profil « fidèle » est en partie défini par le nombre de commandes : c'est attendu, pas une découverte. Le niveau de vie est celui de la commune, pas du client.

def famille(name):
    n = name.upper()
    if n.startswith('BOUGIE GOURMANDE'): return 'Bougies gourmandes'
    if n.startswith(('BOUGIE BOISSON', 'BOUGIE LATTE', 'BOUGIE ICED')): return 'Bougies boisson'
    if n.startswith('BOUGIE PARFUMEE TAILLE S'): return 'Bougies taille S'
    if n.startswith('BOUGIE'): return 'Autres bougies'
    if n.startswith(('BOX DE FONDANTS', 'BOUQUET DE FONDANTS', 'TABLETTE', 'FONDANT')): return 'Fondants'
    if n.startswith(('SUSPENSION VOITURE', 'DIFFUSEUR VOITURE')): return 'Voiture'
    if n.startswith(('DIFFUSEUR', 'RECHARGE MELANGE')): return 'Diffuseurs maison'
    if n.startswith('POUDRE'): return 'Poudre parfumée'
    if n.startswith('ELIXIR'): return 'Élixirs'
    if n.startswith(('PACK FABRICATION', 'PACK BOUGIES')) or 'CONSULTING' in n or n.startswith('RÉGLEMENTATION') or n.startswith('REGLEMENTATION'): return 'Formation'
    return 'Accessoires et cadeaux'

def cle_produit(name):
    """Produit au sens marketing : on retire la variante après ' - ' ou ' / ' (parfum, taille)."""
    return re.split(r' - | / ', name)[0].strip()
